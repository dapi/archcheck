# Состояние и очередь

Первый прототип: YAML-правила, read-only SQLite-адаптер CodeGraph 1.6.2,
прямые запрещённые связи, Ruby/JS интеграционные проверки, текст/JSON и CI-коды.

Следующие инженерные задачи:

- Транзитивные зависимости с объяснимым путём нарушения.
- Baseline для постепенного внедрения в существующем проекте.
- Явные ограниченные исключения с причиной и сроком.
- SARIF для GitHub Code Scanning.
- Правило против циклов между архитектурными компонентами.
- Измерение памяти и времени на крупных публичных Ruby/JS-проектах.
- Проверка разрешения Rails-конвенций и границ неполноты.
- Более стабильный upstream export API вместо доступа к внутренней схеме.
